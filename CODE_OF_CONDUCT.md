# Code of Conduct

## Our pledge

We want Myne to be a welcoming, harassment-free project for everyone who uses it, reads the
specification, or contributes to it, regardless of experience, identity or background. This
applies in issues, pull requests, discussions, commit messages and any other project space.

## Our standards

Behaviour that helps:

- Being kind and specific in review. "This breaks the ratchet because X" is kind; "this is wrong"
  is not.
- Assuming the other person read the code and reached a different conclusion, and asking which
  part they read.
- Giving and gracefully accepting constructive feedback, including on a design that took a long
  time to argue for.
- Crediting other people's work, and respecting licences, including the third-party ones listed in
  [`LICENSING.md`](LICENSING.md).

Behaviour that is not acceptable:

- Harassment, insults, or discriminatory language or imagery.
- Personal or political attacks, and sustained disruption of a discussion.
- Publishing someone's private information, including their email address or the contents of a
  vault. Myne is an end-to-end-encrypted notes app: someone's vault contents or recovery phrase in
  an issue is the same class of harm as doxxing, and it is never an acceptable example, however
  anonymised it looks.
- Misrepresenting a security property. Telling a user that data is safe on the basis of a
  guarantee the code does not make is a serious conduct problem here, not a technical disagreement.

## Scope

This code applies in all project spaces and when an individual is representing the project in
public. It covers the repository, its issue tracker, and the companion repositories under
[`myne-md`](https://github.com/myne-md).

## Enforcement

Maintainers are responsible for clarifying and enforcing these standards. They will remove, edit
or reject comments, commits, code and issues that violate them, and will explain the reason when
they do. Responses escalate with the behaviour: a private word, then a warning, then a temporary
block, then a permanent one.

Report a concern by opening a confidential issue on this repository or by reaching a maintainer
through [myne.md](https://myne.md). Reports are handled privately, and a maintainer who is the
subject of a report will not participate in handling it.

## Attribution

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, with two additions that are specific to this project: the clause about another
person's vault contents, and the clause about misrepresenting a security property.
