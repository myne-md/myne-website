The editor is a single-pane markdown surface. There is no WYSIWYG mode and no
formatting toolbar. You type the markdown source; the formatted version
appears as you scroll past it.

## Source-first

Source is canonical. If you copy text out of Myne and paste into another
markdown app, the formatting comes with you because what you wrote is the
file. We did not invent a format on top of markdown.

### Keyboard

`Ctrl/Cmd-S` saves. `Ctrl/Cmd-K` opens the search panel (Phase 2).
`Ctrl/Cmd-N` creates a new note in the current vault.

## What is not here

There is no rich-text mode, no slash menu, no AI-write button. Those are
reasonable choices for other tools. Myne is for writing markdown by hand.
