# Security Policy

## Reporting a vulnerability

Report security issues to **`security@myne.md`** privately. Do **not** open a public
GitHub issue for a vulnerability.

Include a description and impact, reproduction steps, the affected page or file and
commit, any suggested mitigation, and how you want to be credited. We acknowledge
within 5 business days and aim for an initial assessment within 14 days. We ask for
a 90-day coordinated-disclosure window and will work with you if a fix needs longer.

## Scope

In scope: this repository (the Astro site, `Dockerfile`, `nginx.conf`, scripts and
workflows), the bundle served at `myne.md`, and the links and copy it publishes.
Out of scope: third-party hosts and self-hosted instances run by others; report
those to their operator. Report vulnerabilities in the app itself to
`myne-md/myne`.

We do not publish a PGP key. If your report needs an encrypted transport, contact
us first at `security@myne.md` to arrange one.
