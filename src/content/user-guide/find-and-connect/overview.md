Myne has two kinds of finding: locating a note you have in mind, and seeing how notes relate to each other. This section covers both.

Find looks inside the note you're reading; to search across every note in your vault, use [Search](/user-guide/find-and-connect/search/).

## What's in this section

- **[Wikilinks](/user-guide/find-and-connect/wikilinks/)**: linking notes together, and the three places those links surface.
- **[Backlinks](/user-guide/find-and-connect/backlinks/)**: seeing which notes link to the one you're reading.
- **[Unlinked mentions](/user-guide/find-and-connect/unlinked-mentions/)**: notes that name this one without linking it.
- **[Tags](/user-guide/find-and-connect/tags/)**: grouping notes by `#tag`.
- **[Search](/user-guide/find-and-connect/search/)**: full-text search across the whole vault.
- **[Graph view](/user-guide/find-and-connect/graph-view/)**: a map of your notes and the links between them.
