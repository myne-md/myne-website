This section is about getting files into Myne and keeping track of them. Attachments are images and documents stored inside the encrypted vault; the attachments library is where you see and manage them all; and the importer is a one-time way to bring an existing vault across.

## What's in this section

- **[Attachments](/user-guide/attachments-and-import/attachments/)**: adding images and PDFs to notes, the accepted types and size limits, and how they're stored.
- **[The attachments library](/user-guide/attachments-and-import/attachments-library/)**: browsing, searching, and managing every file in the vault.
- **[Import from Obsidian](/user-guide/attachments-and-import/import-from-obsidian/)**: bringing an existing vault into Myne.
