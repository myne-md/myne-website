This section is about getting files into Myne and keeping track of them. Attachments are files of any type — images, PDFs, and other documents, but also any other file you drop in — stored inside the encrypted vault; voice notes are audio you record straight into a note; the attachments library is where you see and manage them all; and the importer is a one-time way to bring an existing vault across.

## What's in this section

- **[Attachments](/user-guide/attachments-and-import/attachments/)**: adding files to notes — images and PDFs render inline, any other file type is kept as a downloadable card — the accepted types and size limits, and how they're stored.
- **[Voice notes](/user-guide/attachments-and-import/voice-notes/)**: recording audio directly into a note, where it lives as an encrypted attachment.
- **[The attachments library](/user-guide/attachments-and-import/attachments-library/)**: browsing, searching, and managing every file in the vault.
- **[Import from Obsidian](/user-guide/attachments-and-import/import-from-obsidian/)**: bringing an existing vault into Myne. Obsidian `.base` files (saved views) are brought in separately — see [Saved views](/user-guide/editor-and-writing/saved-views/).
