Self-hosting will be available in Phase 2. The protocol is fixed; the server
is in design.

## What is decided

The same protocol that powers the hosted server will run on a self-hosted
instance. The trust boundary is identical — the operator (you, in this
case) cannot read your notes any more than the hosted operator can.

### Why we are not shipping it yet

Phase 1 is the desktop client. The server work runs in parallel but ships
later, intentionally — there is no point in publishing a server image
before the protocol is locked down by Phase 1 going public.

## Where to follow along

The decisions log on the public spec describes what we have settled on so
far. Subscribe to the ledger for new entries.
